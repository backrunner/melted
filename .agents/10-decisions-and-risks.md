# 决策记录与待确认问题

更新日期：2026-10-17。状态：基础阅读链路已实现，完整规划进度见 [实施记录](14-implementation-status.md)。

## 用户已确认

- 产品由 Swift macOS、Swift iOS 和可 self-hosted TypeScript 服务端组成。
- GPL 开源，服务端可以独立工作、支持第三方渠道和插件。
- 首期仅服务端与 macOS；iOS 后续。
- 通用信息处理从首期成立，不局限技术领域；用技术思维实现产品。
- 首批推广群体：开源极客，包括开发者与独立创业者，但不限定他们关注的信息主题。
- 先纯开源、后续再商业化。
- UI 素雅、有设计感、品质感和现代感，符合 Apple HIG；形成设计规范与开发 guard。
- 配色采用阅读器常见的米黄色系，移除绿色；以统一对齐、间距、图标与控件规范保持 UI 整齐。
- 在米白方向上进一步提亮，保持温暖和适合阅读；亮暗色同时兼容，desktop/mobile 统一设计语言并按平台适配。

- 尽量避免 AI slop：不用装饰性 indicator、圆点分割的元信息、井号标签串及模板化文案；通过排版、留白和对齐保持设计感。
- 主入口“阅读”改为“资讯”，分类等筛选并入标题栏以节约空间；用户认可当前方向作为后续实现基线。
- 主界面不要侧栏，设置缩到一个入口；收藏、分类/标签和感兴趣内容使用其他筛选方式组织。

## 风险台账

| 风险 | 严重性 | 处理 / 必须看到的证据 |
| --- | --- | --- |
| AI 整理编造或删除关键限定 | 高 | claim/evidence、数字/否定回归、人工锁定评测 |
| 重大变化被个性化过滤 | 高 | 独立重要性评价、漏报抽样、可回看过滤结果、保留不确定风险 |
| 偏好学习形成茧房或误学 | 高 | 用户硬约束、TTL、可关学习、diff/撤销、探索可关 |
| 自托管/插件泄露正文及 keys | 高 | 可见信任/处理边界、最小权限、隔离/egress 真实测试 |
| APNs 官方 key 泄露/中继滥用 | 高 | 官方 key 仅中继、设备授权绑定、配额/撤销/审计 |
| GPL 与 App Store/依赖冲突 | 高 | 全版权/依赖评审；iOS 发行决策独立门槛 |
| 第三方来源授权及版权争议 | 高 | 授权源、权利记录、失效/删除；AI 改写不免除责任 |
| 社交来源凭据与 Apple 规则冲突 | 高 | 首期不由 App 转交社交凭据；具体服务端授权模式专项核查 |
| 成本与队列失控 | 高 | 原子预留、限时/限步、任务恢复、真实日费用/并发预算 |
| 相似事件误合并 | 中高 | 独立事件负例、可拆分、修正传播 |
| 学习/删除旧状态被恢复 | 中高 | 版本、tombstone、外部删除重试和备份恢复验证 |
| 装机难度导致开源有 star 无使用 | 中 | 独立安装实验、模板、健康诊断、失败文档 |
| 推广群体被误当作产品内容边界 | 中高 | 跨领域 schema/模板/质量评测；不把技术主题设成硬限制 |
| macOS 受众小、通用价值表达不清 | 中 | 开源极客先共建，跨领域结果示例，验证减负/质量后扩平台 |
| 插件标准过大拖慢首期 | 中 | 统一 invoke、小 reference、延后目录和异步协议 |
| 素雅被做成低对比、字号过小或过度玻璃 | 中高 | 语义色/字号缩放、实际背景对比、原生辅助设置矩阵 |
| 远程模板破坏 UI 或伪造状态 | 高 | 受限正文渲染；导航、证据、账户/权限状态由客户端控制 |
| 高序号先提交使同步漏掉低序号更新 | 高 | 账户提交序列锁、稳定 snapshot、乱序提交故障用例 |
| 搜索组件存在但未挂载 | 高 | 恢复主窗口呈现链路，验证菜单/⌘F/chip/关闭及焦点；当前仅源码发现 |
| 反馈、离线与异步状态造成“假成功” | 中高 | 状态机和 revision 映射；真实网络/冲突验证 |

## 设计完成不等于上线完成

本次验收范围为文档覆盖、跨文档一致性、相对链接、JSON 示例、候选色彩对比、参考页和 guard 的静态检查，实际结果记录在 [设计复核](13-design-review.md)。功能/性能/安全/真实模型/macOS/APNs/许可/审核各有独立门槛。后续报告按证据类型说清：源码审查、自动测试、真实运行、签名、公证、审核分别是什么状态。


2026-10-15 用户修订：服务端改 TypeScript，自托管 PostgreSQL + Docker，Cloudflare 全原生基础设施；所有本机服务调试经 Apple Container。当时采用默认 P-256 / 可同步 Keychain 身份，预支持 OIDC 浏览器登录；后由 ADR-017 修订为服务器协商方式。标题栏去掉可见“资讯”，统一 Spotlight 搜索筛选，设置最右，分类轻量胶囊；以上取代早期 Go、独立筛选下拉与无胶囊选择。2026-10-16 再将品牌放到表单标题上方并移除工作台品牌，连接不再滑动；2026-10-17 按用户最新要求恢复列表底栏左侧的紧凑品牌字标；同日统一为 UI v1.0，已知源码差异见 [复核](13-design-review.md)。详见 [迁移](15-typescript-transition.md)。
