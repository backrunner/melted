## 实现范围

- discovery 声明 server_settings v1，独立目录下发分组、表单、读写路径/方法及 versioned-values-v1 JSON 格式
- 分类/标签、内容范围、个人偏好、输出要求均为服务端声明的多行文本，复用原生有限表单控件；客户端没有按偏好字段名分支
- 请求路径限制为当前服务器的 /v1/settings/ 子路径，未知版本/控件/方法/格式拒绝写入
- 两后端按账户保存原文，版本冲突、幂等重试、历史、提交有序 changes 在同一事务提交
- 编辑时保留未保存输入，冲突可获取最新版本并比较；保存失败在固定 footer 显示错误，未保存关闭会确认

当前 application=stored。真实偏好编译、自动分类/打标、个性化过滤/输出与学习未接入，本次不把原文存储算作模型已经应用。协议详见 server/docs/settings.md。

## 原生操作

已重新启动本次编译的 App，使用现有本机开发服务器：

1. 设置中按服务器目录显示“服务器设置 → 内容与输出偏好”
2. 四个字段均有 label、placeholder 和帮助；多行中文/换行编辑、上下滚动与固定操作栏正常
3. 用“界面验证”前缀的临时文字填写四类偏好，真实保存返回“已保存到服务器”；关闭后重新打开，四类原文及换行均保留
