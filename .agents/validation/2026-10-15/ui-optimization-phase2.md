## 5. 服务器连接错误优化（规划中）

### 当前问题
用户勾选"信任服务器"后会看到技术性错误：
```
无法同步，必须使用本机
```

### 优化方案
1. **友好的错误提示**：
   ```
   该服务器不支持远程同步

   你的数据将仅保存在本地。如需在多台设备间同步，
   请联系服务器管理员启用远程同步功能。
   ```

2. **自动降级**：
   - 检测到服务器不支持同步时自动切换到本地模式
   - 不显示错误，只在设置中标注"仅本地"

3. **预检查**：
   - 连接服务器时预先检查能力
   - 在 UI 中清晰标注服务器支持的功能

## 6. Feed 流视图（规划中）

### 设计理念
- 左侧列表不仅是索引，也是内容预览
- 对于简短的资讯（如单条消息、快讯），直接在左侧展示完整内容
- 只有需要详细阅读的长文才在右侧展开

### 实现方案
```swift
// 在 ContentRowView 中
VStack(alignment: .leading, spacing: 6) {
    Text(item.title)

    // 如果内容很短，直接显示
    if item.markdown.count < 200 {
        Text(item.markdown)
            .font(.system(size: 12))
            .foregroundStyle(palette.secondary)
            .lineLimit(3)
    }
}
```

2. **改进排版**：
   - 标题使用更大的字重对比
   - 正文行高从 1.4 增加到 1.6
   - 引用块使用更柔和的左边框

3. **精致的代码块**：
   - 使用 SF Mono 字体
   - 更柔和的背景色
   - 适当的内边距（12pt）
   - 语法高亮（如果可能）

## 设计原则总结

### 视觉层级
- 使用字重、尺寸、颜色来建立清晰的层级
- 避免过多的视觉噪音
- 留白是设计的一部分

### 交互反馈
- 所有交互都有明确的视觉反馈
- 动画自然流畅，不过度
- 状态变化清晰可见

### 一致性
- 统一的圆角、间距、动画参数
- 统一的颜色语义（强调、次要、警告）
- 统一的操作模式

### 性能
- 使用 LazyVStack 优化长列表
- 动画参数保持轻量
- 避免不必要的重绘
