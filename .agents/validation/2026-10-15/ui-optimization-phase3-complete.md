## 已完成的优化

### 1. ✅ Feed 式内容列表

**问题**: 左侧列表过于简单，缺乏内容预览

**解决方案**:
- **更大的内容预览**: 摘要从 2 行增加到 4 行，字体从 12pt 增加到 12.5pt
- **更丰富的标题**: 标题最多显示 3 行，未读用 bold 字重，已读用 medium
- **增强的间距**: 垂直 padding 从 10pt 增加到 14pt，横向从 12pt 增加到 16pt
- **更精致的圆角**: 从 8pt 增加到 10pt
- **收藏标记**: 在时间旁边显示书签图标

**效果**: 用户可以在左侧直接预览更多内容，不需要每次都点开右侧详情

---

### 2. ✅ 时间分区（今日、昨日、本周、更早）

**问题**: 所有内容混在一起，难以快速定位

**解决方案**:
- 使用 `Section` + `pinnedViews` 实现分区
- 分区标题固定在顶部（滚动时保持可见）
- **今日**: 显示 HH:MM 格式
- **昨日**: 显示月日
- **本周**: 显示月日
- **更早**: 显示年月日

**实现细节**:
```swift
private enum TimeSection: String, CaseIterable {
    case today = "今日"
    case yesterday = "昨日"
    case thisWeek = "本周"
    case earlier = "更早"
}
```

**效果**: 用户可以快速定位到特定时间段的内容

---

### 3. ✅ 优化事实依据/核验部分

**问题**: 原设计过于简单，缺乏层级和视觉吸引力

**解决方案**:

#### 收起状态
- **图标徽章**: 36×36pt 圆角矩形，强调色背景，包含放大镜图标
- **双行文本**:
  - 第一行：粗体"事实依据"（14pt semibold）
  - 第二行：依据标签（12pt secondary）
- **chevron 图标**: 右侧带动画的箭头（展开/收起）
- **背景材质**: regularMaterial（毛玻璃效果）
- **描边**: 淡色分隔线（0.5pt）

#### 展开状态
- **编号徽章**: 每个依据前显示圆形编号（1、2、3...）
- **卡片式布局**:
  - 18pt 内边距
  - 12pt 圆角
  - regularMaterial 背景
  - 更大的间距（12pt 标题下方，16pt 卡片之间）
- **查看来源按钮**:
  - 小巧的按钮样式
  - 强调色背景（8% 透明度）
  - 6pt 圆角
  - 图标 + 文字布局
- **空状态优化**:
  - 图标 + 文字居中
  - 更大的垂直留白（24pt）

**效果**: 依据部分现在看起来更加专业和精致，符合原生应用标准

### 6. ✅ 避免列表点击闪烁

**解决方案**:
- 优化动画参数，使用统一的弹簧动画
- `response: 0.2-0.25s`, `dampingFraction: 0.8-0.85`
- 为 `isHovered`, `isSelected`, `item.state.read` 分别添加动画
- 使用 `LazyVStack` 减少不必要的重绘

**效果**: 选中状态变化更加流畅自然

**计划功能**:

- 复制链接
