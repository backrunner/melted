## 本轮修复

- `WorkspaceView` 挂载搜索原生 sheet，⌘F 和有效条件 chip 可以打开，自动聚焦输入，Esc/完成关闭，会话结束时关闭。原生搜索框使用阅读器亮暗语义色，深色提示文字恢复可读。只有 q/分类/标签/关注产生条件 chip，未读或收藏视图不再显示无法清除的冗余 chip。
- 到达依据服务器 upsert 序号，不使用本机时间窗口。首次列表加载前获取同步水位；刷新失败不消费游标，下一次重试；同轮多页变化合并，已有行后续更新可重新触发高亮。保留已加载尾页、分页游标和当前正文，不用整列 spring 驱动布局。
- 到达高亮从实际序号变化触发，500 ms 后局部淡出；取消、移除或 Reduce Motion 不遗留旧的延迟任务。普通阅读/收藏 state 变化不触发到达。
- 液滴触底时刻通过实际下落轮廓求解；修复原来最大约 5.63 pt 的提前碰撞跳变。接触前后复用实际宽、高、拖尾，落地不突变。
- 渐变绘制边界与径向衰减半径一致，消除椭圆裁切产生的轮廓。空态液面位于窗格真正底边，飞溅结束停止绘制，修复底边残留细线。
- 同步更新设计与实现状态文档。原有 `viscous-melt/Continuity.swift` 对应旧的 Contour 实现，不能用它的历史零差异结论证明当前 Field 实现；本轮以新增 Swift 测试和当前画面验证。
