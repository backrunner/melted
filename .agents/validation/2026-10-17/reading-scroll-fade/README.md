# 阅读区滚动遮罩

2026-10-17，macOS 27.0.1（26A434），arm64。当前工作树基于 `d36ff41`，包含其他进行中的改动；本次只接入阅读区渐隐、更新共享组件注释和对应 UI 规范。

## 实现

`ReadingDocumentView` 复用 `ScrollEdgeFade` 的 24 pt 渐隐，按阅读视口与正文几何计算上下隐藏距离。遮罩作用于正文内容，保留原生纵向滚动条、toolbar 和紧凑布局的固定返回按钮。首尾距离为零时恢复不透明；短文无隐藏内容时不渐隐。字号、视口、依据展开或切换文档触发布局后重新计算。沿用共享组件的减少透明度/增强对比度降级。
